# OgImage

Open Graph meta tags generator: build og + Twitter card tags, preview the social card, validate your image. Free dev tool.

## Features
- Meta tag builder for Open Graph + Twitter cards with live social-card preview
- Image-size validator: checks dimensions, aspect ratio, and file size guidance
- Validator checklist covering the six most common card failures, plus one-click snippet copy
